# Setup Instructions

## 1. Setup steps-Backend

```bash
git clone https://github.com/FahadUrRehman-13/simple-notes-app.git
cd notes-app
cd server
npm install
npm start
```

## 2. Setup steps-Backend

```bash
cd notes-app
cd client
npm install
npm run dev
```
Open this address in a browser : http://localhost:5173.
